**心得体会：**

1、任务添加过程中，后期执行时长明显变长。因此哪怕是小项目，也应当养成要求 ai 维护一个工作文档的好习惯，避免 ai 阅读整个文件产生大量浪费。

2、应当一次性将一类功能要求 ai 完全实现：如三列状态栏，应当在定义状态栏的时候就要求 ai 实现。实际按照前面提示词实现，实现三列状态栏消耗大量时间，实际可以避免。
