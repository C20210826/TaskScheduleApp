一、项目概览
--------------------------------------------------------------------------------
- 项目名称：task-manager-app（任务管理应用）
- 技术栈：Vue 3（组合式 API，<script setup>）+ Vite 5 + Tailwind CSS 3 + localStorage
- 定位：纯前端单页应用，无后端，数据保存在浏览器 localStorage
- 运行环境：Node.js（package.json 声明 "type": "module"，全项目使用 ES Module）

常用命令（在项目根目录执行）：
- 安装依赖       npm install
- 启动开发服务器  npm run dev      （默认 5173，被占用会自动换端口）
- 生产构建       npm run build     （产物输出到 dist/）
- 预览构建产物    npm run preview

三、数据模型
--------------------------------------------------------------------------------
任务（task）对象结构，保存在 localStorage 键 "task-manager.tasks" 下（JSON 数组）：

{
  id:          string   // 唯一标识，crypto.randomUUID() 生成；不可用时回退时间戳+随机数
  title:       string   // 必填，已 trim
  description: string   // 选填，已 trim；为空字符串表示无描述
  priority:    string   // 'high' | 'medium' | 'low'
  status:      string   // 'todo' | 'doing' | 'done'
  createdAt:   string   // ISO 时间字符串
  updatedAt:   string   // ISO 时间字符串
}

状态枚举（src/constants.js）：
- TASK_STATUS   = { todo: 'todo', doing: 'doing', done: 'done' }
- TASK_STATUS_META = [{ value, label }]  // label: 待办 / 进行中 / 已完成

优先级枚举（src/constants.js）：
- TASK_PRIORITY = { high, medium, low }
- TASK_PRIORITY_META 每项包含字段：
    value              优先级值
    label              显示标签（高 / 中 / 低）
    badgeClass         徽章浅色样式
    darkBadgeClass     徽章深色样式
    titleClass         标题浅色样式
    darkTitleClass     标题深色样式
    dotClass           状态点颜色（当前未在 UI 使用，保留占位）
    activeClass        选中态样式（深/浅共用）
    inactiveClass      未选中态浅色样式
    darkInactiveClass  未选中态深色样式

主题存储键：
- "theme"，取值 'dark' | 'light'，由 useTheme.js 与 index.html 内联脚本共同读写。

四、核心机制说明（改动时必须关注）
--------------------------------------------------------------------------------

【1】任务持久化（src/composables/useTasks.js）
- 模块顶部 STORAGE_KEY = 'task-manager.tasks'，全应用唯一写入点。
- loadTasks()：启动时从 localStorage 读取；JSON.parse 失败或非数组时回退空数组，不抛错。
- saveTasks()：JSON.stringify 写入 localStorage，try/catch 静默失败（隐私模式等）。
- useTasks() 返回 { tasks, addTask, updateTask, removeTask }；内部
  watch(tasks, saveTasks, { deep: true }) 保证每次增删改都自动写入。
- addTask 默认 priority=medium、status=todo，新任务插入数组头部。
- updateTask 只更新传入 patch 字段并刷新 updatedAt。
- removeTask 按 id 过滤。

【2】深色模式（class 策略，src/composables/useTheme.js + index.html + tailwind.config.js）
- tailwind.config.js 必须保持 darkMode: 'class'，否则所有 dark:* 变体失效（这也是
  历史反馈"只有按钮没有效果"的根因来源之一）。
- index.html <head> 内联脚本：在 Vue 挂载前读取 localStorage['theme']，若为 'dark'
  则给 <html> 加 .dark 类，用于防止刷新时白屏闪烁（FOUC）。
- useTheme.js：isDark 响应式状态以 <html> 是否含 .dark 为准；applyTheme 切换
  document.documentElement 的 .dark 类并写回 localStorage；watch(immediate) 统一同步。
- src/style.css 的 color-scheme: light / html.dark { color-scheme: dark } 用于让
  滚动条、输入光标、自动填充等浏览器原生控件跟随主题。

【3】状态流转（看板拖拽）
- App.vue 用 computed columns 把 tasks 按 status 分组为 { todo:[], doing:[], done:[] }，
  传给 KanbanBoard。
- KanbanBoard 的拖拽事件流：
    TaskItem 的 @dragstart/ @dragend -> handleDragStart/handleDragEnd 记录 draggingTaskId；
    列的 @dragover.prevent 高亮、@drop.prevent 触发 handleDrop(status)，
    最终 emit('change-status', { id, status }) 一路冒泡到 App.vue 的 handleChangeStatus
    -> updateTask(id, { status })。
- 拖拽用原生 HTML5 drag & drop，没有引入第三方拖拽库。

【4】组件事件契约（父子通信全为 events + props，无全局状态库）
- App.vue -> KanbanBoard(props: tasksByStatus, editingTaskId；
    events: edit/remove/save/cancel-edit/change-status)。
- KanbanBoard -> TaskItem(props: task, editing；
    events: edit/remove/save/cancel-edit/drag-start/drag-end)。
- TaskItem 编辑态内部渲染 TaskForm（初始值来自 task 的 initialTask prop），
  提交时 save 事件回传 { id, title, description, priority }。
- TaskForm 对外：props(initialTask, submitText)，events(submit, cancel)。
  表单提交时校验 title.trim() 非空，否则 error 提示"标题为必填项，请输入任务标题"。

五、样式约定（Tailwind）
--------------------------------------------------------------------------------
- Tailwind content 扫描范围见 tailwind.config.js：
    ['./index.html', './src/**/*.{vue,js,ts,jsx,tsx}']
- 重要：所有 Tailwind 类必须是完整字符串字面量，不能动态拼接（如 'bg-' + color），
  否则 content 扫描不到、类不会生成。constants.js 中每档优先级颜色用独立字段
  （badgeClass / darkBadgeClass / titleClass / darkTitleClass 等）就是为了规避拼接。
- 新增组件/新类后需确认：类名完整出现在 .vue/.js 中；改动 tailwind.config.js 或
  新增动态颜色后需重启 dev server（Vite 对 tailwind.config.js 的变化不会热更新）。
- 深色适配模式：每个浅色元素都补 dark: 前缀变体，通过 html.dark 类整体切换。
